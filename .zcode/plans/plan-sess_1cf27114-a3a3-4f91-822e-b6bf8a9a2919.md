## Set up Laravel Octane (FrankenPHP) — production only

### Gaps found
1. `OCTANE_SERVER` isn't passed into the container by compose, and `.env.example` lacks it → production falls back to uninstalled RoadRunner → crash loop.
2. Entrypoint still runs classic FrankenPHP in production.
3. `static $currencyCache` in `format_price()` (app/helpers.php:60) leaks memory + serves stale currency data under Octane.

### Changes

**1. `docker-compose.yml`** — add to `x-app-env` anchor:
```yaml
OCTANE_SERVER: "${OCTANE_SERVER:-frankenphp}"
```

**2. `config/octane.php`** (line 41) — safe default:
```php
'server' => env('OCTANE_SERVER', 'frankenphp'),
```

**3. `.env.example`** — append:
```
OCTANE_SERVER=frankenphp
```

**4. `docker/entrypoint.sh`** — replace production branch (lines 127–139); dev stays on `artisan serve`:
```sh
if [ "$APP_ENV" = "production" ]; then
    echo "==> Starting Octane (FrankenPHP) on :8000..."
    if [ "$(id -u)" = "0" ]; then
        exec gosu www-data php artisan octane:start --server=frankenphp --host=0.0.0.0 --port=8000
    fi
    exec php artisan octane:start --server=frankenphp --host=0.0.0.0 --port=8000
else
    echo "==> Starting artisan serve (local — instant reloads, no opcache)..."
    exec php artisan serve --host=0.0.0.0 --port=8000
fi
```

**5. `app/Models/Currency.php`** — add Redis-backed cache (mirrors `Setting`):
- `CACHE_KEY` constant, `getAllCached()` returning `code => ['symbol','exchange_rate']` via `Cache::rememberForever`, `clearCache()`, and `saved`/`deleted` events that clear it.

**6. `app/helpers.php`** — in `format_price()`, remove `static $currencyCache` and read from `Currency::getAllCached()` instead.

**7. `README.md`** — update "Production differences" bullet to mention Octane.

### Unchanged (verified)
- queue/scheduler override entrypoint → never hit Octane branch.
- healthcheck pings `/up:8000` → works under Octane.
- `config/octane.php` already has standard flush listeners; audit found no other static state, custom singletons, or leaked request auth.

### Verify after deploy
```sh
docker compose -f docker-compose.yml -f docker-compose.prod.yml build
docker compose -f docker-compose.yml -f docker-compose.prod.yml up -d
docker compose logs -f app   # "==> Starting Octane (FrankenPHP)..."
curl http://127.0.0.1:${APP_PORT}/up
```

### Risk
Low — config-only infra changes with safe defaults; one isolated helper change.
